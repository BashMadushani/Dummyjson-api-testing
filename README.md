# 🔌 DummyJSON REST API Testing – Postman

## 📌 Project Overview

This project focuses on functional API testing using Postman on the DummyJSON REST API.

The purpose of this project was to verify API endpoints, validate request and response behaviour, check HTTP status codes, and evaluate API functionality through positive and negative test scenarios.

## 🎯 Testing Objectives

- Verify REST API endpoints.
- Validate HTTP request methods.
- Check API response status codes.
- Validate JSON response structures and data.
- Test positive and negative scenarios.
- Verify product retrieval and search functionality.
- Test pagination behaviour.
- Document test cases and execution evidence.

## 🌐 API Under Test

- **API:** DummyJSON REST API
- **Base URL:** https://dummyjson.com
- **API Documentation:** https://dummyjson.com/docs
- **Testing Tool:** Postman

## 🧪 Testing Activities

The following API testing activities were performed:

| Testing Area | Description |
|---|---|
| GET Request | Retrieve product information |
| POST Request | Test product creation endpoint |
| PUT Request | Test product update endpoint |
| DELETE Request | Test product deletion endpoint |
| Search Testing | Verify product search functionality |
| Pagination Testing | Validate limit and skip parameters |
| Positive Testing | Verify valid requests |
| Negative Testing | Verify invalid inputs and requests |
| Status Code Validation | Check HTTP response status codes |
| JSON Validation | Verify response structure and data |
